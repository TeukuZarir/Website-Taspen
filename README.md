# HadirKerja

Aplikasi absensi magang cerdas berbasis React.

## Prasyarat
- Node.js (versi 16 atau lebih baru)
- NPM (biasanya terinstall bersama Node.js)

## Cara Menjalankan (Lokal)

1.  **Install Dependencies**
    Jalankan perintah ini di terminal untuk mengunduh pustaka yang dibutuhkan (React, Recharts, dll):
    ```bash
    npm install
    ```

2.  **Jalankan Server**
    ```bash
    npm run dev
    ```
    Aplikasi akan berjalan di `http://localhost:3000`.
